Block: logic_operation

What is it for?

Combines two conditions: ‘and’ returns true if both are true; ‘or’ returns true if at least one is true.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Attach a condition on each side, then choose and or or in the block's list.

Good to know

  • To combine more than two conditions, put an ‘and’ (or ‘or’) block inside another one.

Example

A heart shows only when buttons A and B are pressed together.
