Kitrobot v2: spin left

Block: kitrobot_pivoter_gauche

What is it for?

Makes the robot turn on the spot to the left, by about a quarter turn, then stops it.

How to use it?

Chain this block with the ‘move forward one square’ and ‘move back one square’ blocks.

Good to know

  • The robot spins at 50 % for 0.4 second: the angle obtained (about 90°) depends on the floor and the load.
  • The program waits for the end of the movement before moving on to the next block.

Example

The robot moves forward one square, spins right, moves forward one more square, then moves back one square.
