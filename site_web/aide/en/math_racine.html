square root …

Block: math_racine

What is it for?

Returns the square root of a number: the square root of 16 is 4, because 4 × 4 = 16.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Attach the number.

Good to know

  • The result is a decimal number (4.0).
  • The square root of a negative number stops the program with an error.

Example

At start, the square root of 16 (that is 4) shows.
