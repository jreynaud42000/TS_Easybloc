Maqueen Plus v3: at right junctions, go …

Block: maqueen_v3_mode_droite

What is it for?

Chooses what the V3 robot does, during line following, when a branch goes to the right: go straight on, turn right or stop.

How to use it?

Put this block in the ‘on start’ block, before starting the line follower.

Good to know

  • This block needs a Maqueen Plus V3 chassis: V1 and V2 chassis do not have this built-in line follower.

Example

The follower speed is set to 3, the robot goes straight on at crossroads, then line following starts.
