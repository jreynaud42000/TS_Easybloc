not …

Block: logic_negate

What is it for?

Reverses a condition: returns true when the condition is false, and false when it is true.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Attach the condition to reverse.

Good to know

  • ‘not button A is pressed’ is true as long as A is not pressed.

Example

A sad face shows while button A is not pressed, a happy face otherwise.
