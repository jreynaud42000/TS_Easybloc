if … return …

Block: procedures_ifreturn

What is it for?

In a function that returns a value, returns at once the given value if the condition is true; the rest of the function is then not run.

How to use it?

Put this block inside a ‘to do something … return’ block.

Attach the condition, then the value to return.

Good to know

  • This block can only be used in a function.

Example

The ‘limiter’ function returns the number it receives, but never more than 9: 25 gives 9, which shows.
