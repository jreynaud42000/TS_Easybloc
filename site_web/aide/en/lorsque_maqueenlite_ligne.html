when the line sensor … changes to state …

Block: lorsque_maqueenlite_ligne

What is it for?

Runs the blocks inside it when the left or right line sensor of the Maqueen Lite changes state: it goes to high (1) or to low (0).

How to use it?

Choose the sensor, then the expected state.

Put this block on its own in the workspace: it does not attach to any other block.

Good to know

  • The block runs when the state changes, not while the state lasts.
  • The state is checked at each turn of the program's main loop.

Example

A heart shows when the left line sensor goes to high (1).
