colour the whole strip R … V … B …

Block: grove_ruban_perso

What is it for?

Lights up all the LEDs of the strip in a colour you mix with red (R), green (V on the block) and blue (B).

How to use it?

Type the amount of red, green and blue, each from 0 to 255 (0, 0, 0 = off; 255, 255, 255 = white).

Good to know

  • Mixing colours: red + green = yellow, red + blue = purple, green + blue = cyan.
  • The colour takes into account the brightness set with the ‘strip brightness to … %’ block.

Example

Red 255, green 128, blue 0: the strip lights up in orange.
