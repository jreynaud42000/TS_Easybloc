Block: bouton_est_appuye

What is it for?

Returns true while the chosen button is held down, false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Choose the button: A, B, or A+B (both at the same time).

Put this block in an ‘if’ or ‘wait until’ block.

Good to know

  • It returns the state of the button at the moment the program reads it: a very short press, during a ‘wait’ block, can be missed.
  • In the simulator, press buttons A and B of the drawn board.

Example

Button A shows a heart, button B clears the screen.
