LiDAR: emergency signal on?

Block: lidar_urgence

What is it for?

Returns true when the LiDAR has detected a very close obstacle, less than 100 mm away, false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Put this block in an ‘if’ block, after the ‘LiDAR: get the avoidance data’ block.

Good to know

  • The result comes from the last acquisition: put the ‘get the avoidance data’ block just before.
  • In the simulator, set the distances with the sliders of the ‘LiDAR’ panel.

Example

After each acquisition, a sad face shows if an obstacle is less than 100 mm away.
