Block: logic_compare

What is it for?

Compares two values and returns true or false: equal (=), different (≠), smaller (<), smaller or equal (≤), bigger (>), bigger or equal (≥).

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Attach a value on each side, then choose the comparison in the block's list.

Put this block in an ‘if’ or ‘repeat while’ block.

Good to know

  • With a measurement that changes a little all the time (temperature, light), prefer < or > to =: the exact value may never be reached.
  • You can also compare two texts: ‘=’ checks that they are identical.

Example

A sad face shows when the board's temperature is above 25 °C, a happy face otherwise.
