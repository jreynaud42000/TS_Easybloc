T&H sensor: …

Block: grove_th_mesure

What is it for?

Returns the temperature (in °C or °F) or the air humidity (in %) measured by the Grove I2C temperature and humidity sensor.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the quantity: temperature (°C), temperature (°F) or humidity (%).

Good to know

  • The result can be a decimal number.
  • In the simulator, set the values with the sliders of the ‘Peripherals’ table.

Example

The temperature measured by the sensor shows every second.
