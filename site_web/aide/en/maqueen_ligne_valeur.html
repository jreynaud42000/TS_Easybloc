raw value of line sensor …

Block: maqueen_ligne_valeur

What is it for?

Returns the raw value measured by one of the robot's five line sensors: it changes with the colour and the brightness of the surface.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the sensor: L2, L1, M, R1 or R2.

Show the value above the line, then next to it, to choose a threshold to compare in an ‘if’ block.

Good to know

  • To simply know whether the sensor sees the line or not, the ‘line sensor … on the line’ block is simpler.

Example

The value of the middle sensor shows every second on the LED matrix.
