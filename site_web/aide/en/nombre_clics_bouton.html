number of clicks of button …

Block: nombre_clics_bouton

What is it for?

Returns the total number of clicks on the chosen button since the board started.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the button: A or B.

Compare the result with a number in an ‘if’ block, or show it.

Good to know

  • The counter never goes back to 0 by itself: it counts all the clicks since the start, even spaced out.
  • A click is counted even if the program was busy elsewhere at that moment.

Example

A heart shows when button B has been pressed 10 times in all.
