a QR code is visible

Block: ia_qr_visible

What is it for?

Returns true while the computer's camera sees a QR code (or a barcode), false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Put this block in an ‘if’ block, in the ‘forever’ block.

Good to know

  • Reading happens on the computer: in the AI window, ‘QR code’ tab, click ‘▶ Read the codes’. The board receives the text through the USB cable.
  • It becomes false again less than a second after the code disappears.

Example

A happy face shows while a code is visible; otherwise the screen is empty.
