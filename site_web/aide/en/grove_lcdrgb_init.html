set up the RGB LCD screen (V4.0)

Block: grove_lcdrgb_init

What is it for?

Prepares the Grove RGB LCD screen (version 4.0): 2 lines of 16 characters, with a lit background whose colour you choose.

How to use it?

Put this block in the ‘on start’ block, before the other screen blocks.

Good to know

  • This block is optional: The screen plugs into an I2C port; it is prepared by itself the first time it is used. The background then lights up in white.
  • According to this module's documentation, it needs a 5 V power supply.

Example

The RGB LCD screen is prepared, then ‘Hello’ is written on the first line.
