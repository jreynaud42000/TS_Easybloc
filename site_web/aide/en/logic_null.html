null

Block: logic_null

What is it for?

Returns the value null: ‘no value’.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Store it in a variable to show that it does not contain anything yet.

Good to know

  • In the Python program, null is written None.
  • This block is rarely used: for a number, starting at 0 is often better.

Example

A variable gets the value null at start, then it is written in the console (None).
