set the 4-digit display: CLK … DIO …

Block: grove_4d_definir

What is it for?

Tells which pins the Grove 4-digit display is plugged into: CLK (clock) and DIO (data).

How to use it?

Put this block in the ‘on start’ block, before the other display blocks.

Choose the two pins: those of the Grove port the display is plugged into.

Good to know

  • This block is optional: without it, the display is taken with CLK on P0 and DIO on P1.

Example

The display is set (CLK on P0, DIO on P1), its brightness is set to 3, then 1234 shows.
