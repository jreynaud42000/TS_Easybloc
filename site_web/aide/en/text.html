Block: text

What is it for?

Returns the text written in the block.

This block returns a text (to show, or to compare with another text using the ‘=’ block of the Logic category).

How to use it?

Click in the block to type the text.

Good to know

  • A text that contains digits stays a text: ‘12’ is not calculated like the number 12.
  • The LED matrix does not show accented letters.

Example

The text ‘Hello!’ scrolls once at start.
