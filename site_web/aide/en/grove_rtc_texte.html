clock: time as text (hh:mm:ss)

Block: grove_rtc_texte

What is it for?

Returns the real-time clock's time as text ‘hh:mm:ss’, for example ‘08:05:30’.

This block returns a text (to show, or to compare with another text using the ‘=’ block of the Logic category).

How to use it?

Show the text on the LED matrix (‘scroll’ block) or on a screen (LCD, OLED…).

Good to know

  • Numbers smaller than 10 are written with a 0 in front: 8:5 becomes ‘08:05’.

Example

The clock is set once at start, then the time scrolls every 5 seconds.
