Maqueen Lite: line sensor … (0 or 1)

Block: maqueenlite_ligne

What is it for?

Returns the state of the left or right line sensor, under the robot: 0 or 1.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the sensor: left or right.

Compare the result with 0 or 1 in an ‘if’ block.

Good to know

  • The left sensor is read on pin P13, the right one on P14.
  • Which value means the black line depends on the sensor: check it on your robot by putting the sensor on the line, then next to it.

Example

A happy face shows when the left line sensor is at 1.
