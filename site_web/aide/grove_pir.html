Bloc : grove_pir

À quoi ça sert ?

Renvoie vrai quand le détecteur de mouvement Grove (capteur PIR) voit bouger une personne ou un animal devant lui, faux sinon.

Ce bloc renvoie une réponse vrai/faux (à brancher directement dans un bloc « si », ou dans un bloc de la catégorie Logique).

Comment l'utiliser ?

Choisissez la broche où le détecteur est branché.

Mettez ce bloc directement dans un bloc « si ».

À savoir

  • Il sent la chaleur d'un corps qui bouge : un objet froid qui bouge ne le déclenche pas.
  • Après un mouvement, il reste à vrai quelques secondes.
  • Dans le simulateur, cliquez sur la lentille blanche du détecteur dans le montage, ou cochez « mouvement détecté » dans le tableau « Périphériques ».

Exemple

Le buzzer branché sur P1 bipe quand le détecteur de mouvement branché sur P0 voit bouger.
