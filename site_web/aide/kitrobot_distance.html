Kitrobot v2 : distance (cm)

Bloc : kitrobot_distance

À quoi ça sert ?

Renvoie la distance entre le robot et l'obstacle le plus proche, en centimètres, mesurée par son capteur à ultrasons.

Ce bloc renvoie un nombre (à brancher dans un autre bloc, là où on attend un nombre, ou dans un bloc de comparaison = < >).

Comment l'utiliser ?

Affichez la valeur, ou comparez-la à un nombre dans un bloc « si » (par exemple pour s'arrêter avant un mur).

À savoir

  • Le capteur est lu sur la broche P0, sauf si le bloc « Kitrobot v2 : capteur ultrason sur … » en indique une autre.
  • Dans le simulateur, réglez la distance avec le curseur de distance du robot.

Exemple

La distance mesurée devant le robot s'affiche chaque seconde sur la matrice de LED.
