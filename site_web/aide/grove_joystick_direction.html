joystick X … Y … vers …

Bloc : grove_joystick_direction

À quoi ça sert ?

Renvoie vrai quand le joystick est poussé dans la direction choisie (haut, bas, gauche, droite), ou quand il est au centre.

Ce bloc renvoie une réponse vrai/faux (à brancher directement dans un bloc « si », ou dans un bloc de la catégorie Logique).

Comment l'utiliser ?

Choisissez les broches des axes X et Y, puis la direction.

Mettez ce bloc dans un bloc « si », dans le bloc « répéter indéfiniment ».

À savoir

  • Le joystick compte comme poussé quand l'axe passe sous 350 ou au-dessus de 700 (sur 1023).
  • Pour une commande plus fine, lisez la valeur exacte avec le bloc « valeur du joystick sur … ».

Exemple

Un visage heureux s'affiche quand le joystick (axes sur P0 et P1) est poussé vers le haut.
