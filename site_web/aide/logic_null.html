nul

Bloc : logic_null

À quoi ça sert ?

Renvoie la valeur nul : « aucune valeur ».

Ce bloc renvoie un nombre (à brancher dans un autre bloc, là où on attend un nombre, ou dans un bloc de comparaison = < >).

Comment l'utiliser ?

Rangez-le dans une variable pour indiquer qu'elle ne contient encore rien.

À savoir

  • Dans le programme Python, nul s'écrit None.
  • Ce bloc sert rarement : pour un nombre, on préfère souvent commencer à 0.

Exemple

Une variable reçoit la valeur nul au démarrage, puis elle est écrite dans la console (None).
