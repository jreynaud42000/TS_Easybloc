Kitrobot v2 : capteur de ligne gauche … droit …

Bloc : kitrobot_definir_lignes

À quoi ça sert ?

Indique la ou les broches où sont branchés les capteurs de ligne gauche et droit du robot, si ce ne sont pas celles par défaut.

Comment l'utiliser ?

Placez ce bloc dans le bloc « au démarrage », avant les autres blocs Kitrobot v2.

Choisissez la ou les broches.

À savoir

  • Ce bloc est facultatif : sans lui, le logiciel utilise P13 pour le capteur gauche et P14 pour le capteur droit.
  • Le câblage du Kitrobot v2 n'a pas de documentation publique : les broches par défaut sont un choix du logiciel. Vérifiez le câblage de votre robot.

Exemple

Les capteurs de ligne sont déclarés sur P1 (gauche) et P2 (droit) ; un visage heureux s'affiche quand le capteur gauche voit la ligne.
