true / false

Block: logic_boolean

What is it for?

Returns the value true or the value false, chosen in the block's list.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Store it in a variable to remember a state: on or off, game in progress or over…

Good to know

  • With the ‘not’ block, you can easily switch from one state to the other: ‘set on to not on’.

Example

Button A turns the heart on or off: the ‘allume’ (on) variable switches between true and false.
