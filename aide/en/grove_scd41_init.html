set up the CO₂ sensor SCD41

Block: grove_scd41_init

What is it for?

Prepares the SCD41 CO₂ sensor, which also measures temperature and humidity.

How to use it?

Put this block in the ‘on start’ block.

Good to know

  • This block is optional: the sensor is prepared by itself at its first measurement.
  • The sensor plugs into an I2C port.

Example

The sensor is prepared, then the CO₂ (in ppm) shows every second.
