Block: ia_classe_est

What is it for?

Returns true while the last class recognised by the AI (camera or microphone) is the chosen one, false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Choose vision or sound, then the class.

Put this block in an ‘if’ block, in the ‘forever’ block.

Good to know

  • Recognition happens on the computer (PC camera or microphone, AI window): the board only receives the result, through the USB cable. Keep the board plugged in and EasyBloc open.
  • It becomes false again when the AI's confidence drops below the confidence threshold set in the AI window.

Example

While the camera recognises ‘Cat’, a heart is shown; otherwise the screen is empty.
