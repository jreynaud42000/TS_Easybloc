Block: math_constrain

What is it for?

Returns a number brought back between two limits: if it is too small, it becomes the low limit; too big, the high limit.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Attach the number, then the low limit and the high limit.

Good to know

  • Handy to keep a value within what a module accepts, for example a servomotor angle between 0 and 180.
