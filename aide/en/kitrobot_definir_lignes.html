Kitrobot v2: left line sensor … right …

Block: kitrobot_definir_lignes

What is it for?

Tells which pin(s) the left and right line sensors of the robot are plugged into, if they are not the default ones.

How to use it?

Put this block in the ‘on start’ block, before the other Kitrobot v2 blocks.

Choose the pin(s).

Good to know

  • This block is optional: without it, the software uses P13 for the left sensor and P14 for the right sensor.
  • The Kitrobot v2 wiring has no public documentation: the default pins are a choice of the software. Check the wiring of your robot.

Example

The line sensors are set on P1 (left) and P2 (right); a happy face shows when the left sensor sees the line.
