push button on … pressed

Block: grove_bouton_appuye

What is it for?

Returns true while the Grove push button is held down, false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Choose the button's pin.

Put this block in an ‘if’ block, in the ‘forever’ block.

Good to know

  • To react once per press, use the ‘when the push button on … is pressed’ block instead.
  • In the simulator, keep clicking on the button drawn in the wiring.

Example

A heart shows while the push button (P0) is held down.
