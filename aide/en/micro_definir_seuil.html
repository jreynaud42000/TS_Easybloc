set the sound threshold … to …

Block: micro_definir_seuil

What is it for?

Sets the sound level above which a sound is ‘loud’ (or below which it is ‘quiet’) for the ‘when the sound … is detected’ block.

How to use it?

Choose ‘loud’ or ‘quiet’, then type the threshold, from 0 to 255 (like the ‘sound level’ block).

Put it in the ‘on start’ block.

Good to know

  • The higher the ‘loud’ threshold, the more noise is needed to run the block.
  • The microphone only exists on the micro:bit V2 board. The simulator hears no sound.

Example

With a threshold of 200, only loud enough noises show the sad face.
