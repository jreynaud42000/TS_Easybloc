pick random true or false

Block: math_random_bool

What is it for?

Returns true or false at random, one chance in two, like heads or tails.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Put this block in an ‘if’ block.

Good to know

  • A new draw is made each time the program reaches this block.

Example

Each press on button A flips a coin: happy face or sad face.
