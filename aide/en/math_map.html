Block: math_map

What is it for?

Changes a value from a starting range to another range: for example a measurement from 0 to 1023 into a value from 0 to 4.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Attach the value, then the two limits of the starting range, then the two limits of the target range.

Good to know

  • The result is often a decimal number: round it with the ‘round’ block if needed.
  • A value outside the starting range gives a result outside the target range: use the ‘constrain’ block to limit it.

Example

The light level (0 to 255) is changed into a value from 0 to 4, which shows every second.
