clock: …

Block: grove_rtc_lire

What is it for?

Returns one part of the real-time clock's date or time: the hour (0 to 23), the minute, the second, the day, the month or the year.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the part to read.

Compare it with a number in an ‘if’ block to trigger an action at a precise time.

Good to know

  • To react at a precise time (an alarm clock), test the hour and the minute together with the ‘and’ block.
  • The clock must first have been set with the ‘set the clock to …’ block.

Example

The buzzer plugged into P0 sounds at 7:30.
