sound level

Block: micro_intensite_son

What is it for?

Returns the level of the sound heard by the board's microphone, from 0 (silence) to 255 (very loud).

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Show the value, or compare it with a number in an ‘if’ block.

Good to know

  • The microphone only exists on the micro:bit V2 board.
  • In the simulator, this measurement does not change (it is always 0): try the program on the real board.

Example

The sound level shows every second on the LED matrix.
