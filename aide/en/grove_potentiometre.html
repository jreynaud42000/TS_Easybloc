Block: grove_potentiometre

What is it for?

Returns the position of the knob of the Grove potentiometer (a knob you turn).

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the module's pin: P0, P1 or P2 (the analogue inputs).

Choose the unit: the raw value from 0 to 1023, the angle from 0 to 300° (the travel of the knob) or the percentage from 0 to 100 %.

Good to know

  • Only pins P0, P1 and P2 can read a value between 0 and 1023.
  • In the simulator, turn the knob drawn in the wiring, or the ‘Potentiometer’ slider in the ‘Peripherals’ table.

Example

The angle of the potentiometer plugged into P0 is shown on the LED matrix, then the measurement starts again.
