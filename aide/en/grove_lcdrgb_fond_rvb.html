RGB LCD: backlight red … green … blue …

Block: grove_lcdrgb_fond_rvb

What is it for?

Sets the background colour of the RGB LCD screen by mixing red, green and blue.

How to use it?

Type the amount of each colour, from 0 to 255 (0, 0, 0 = background off; 255, 255, 255 = white).

Good to know

  • A value outside 0 to 255 is brought back to 0 or 255.
  • If the backlight is off, the colour is kept and appears at the next ‘turn on the backlight’.

Example

The background takes an orange colour (red 255, green 128, blue 0), then ‘Orange’ shows.
