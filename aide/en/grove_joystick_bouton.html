joystick button on … pressed

Block: grove_joystick_bouton

What is it for?

Returns true when you press the stick of the Grove joystick, false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Choose the pin of the joystick's X axis.

Put this block in an ‘if’ block.

Good to know

  • The press is recognised because it makes the X axis drop below 250: pushing the stick fully to the left can give the same result.

Example

A heart shows when you press the joystick's stick.
