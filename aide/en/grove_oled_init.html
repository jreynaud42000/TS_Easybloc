set up the OLED screen 0.96"

Block: grove_oled_init

What is it for?

Prepares the small 0.96-inch Grove OLED screen: 8 lines of 21 characters.

How to use it?

Put this block in the ‘on start’ block, before the other screen blocks.

Good to know

  • This block is optional: The screen plugs into an I2C port; it is prepared by itself the first time it is used.

Example

The OLED screen shows two lines, waits two seconds, then clears.
