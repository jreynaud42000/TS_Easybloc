Maqueen Lite: distance (cm) ultrasonic sensor

Block: maqueenlite_distance

What is it for?

Returns the distance between the front of the robot and the nearest obstacle, in centimetres, measured by the ultrasonic sensor.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Show the value, or compare it with a number in an ‘if’ block (for example to stop before a wall).

Good to know

  • The sensor uses pins P1 (trigger) and P2 (echo), fixed by the robot: they cannot be used for anything else.
  • It returns 0 when no echo comes back (obstacle too far, or a surface that absorbs sound).
  • In the simulator, set the distance with the robot's distance slider.

Example

The distance measured in front of the robot shows every second on the LED matrix.
