Block: broche_est_pressee

What is it for?

Returns true while pin P0, P1 or P2 is touched with a finger, false otherwise.

This block returns a true/false answer (to plug straight into an ‘if’ block, or into a block from the Logic category).

How to use it?

Choose the pin.

Put this block in an ‘if’ or ‘wait until’ block.

Good to know

  • One finger on the pin is enough: the touch mode of the V2 board is switched on automatically.
  • In the simulator, click pin 0, 1 or 2 of the drawn board.

Example

A happy face shows while pin P0 is touched.
