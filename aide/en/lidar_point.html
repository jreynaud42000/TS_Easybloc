LiDAR …: distance measured at point x … y … (mm)

Block: lidar_point

What is it for?

Returns the distance, in millimetres, measured by the LiDAR at point (x, y) of its 8×8 grid.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the sensor's address, then type x and y, from 0 to 7.

Good to know

  • This block only works in 8x8 matrix mode: put the ‘LiDAR …: set the size 8x8 matrix’ block in the ‘on start’ block.
  • It asks the sensor each time: the ‘get the avoidance data’ block is not needed here.

Example

The LiDAR is prepared in 8×8 matrix mode, then the distance measured at point (3, 3) shows every second.
