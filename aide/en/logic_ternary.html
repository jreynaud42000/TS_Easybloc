test … if true … if false …

Block: logic_ternary

What is it for?

Returns one value or another depending on a condition: the ‘if true’ value when the condition is true, the ‘if false’ value otherwise.

This block returns a text (to show, or to compare with another text using the ‘=’ block of the Logic category).

How to use it?

Attach the condition in ‘test’, then one value in ‘if true’ and another in ‘if false’.

Put this block where a value is expected: show, store in a variable…

Good to know

  • The result has the type of the chosen values: a number, a text… (here, a text).
  • It is a short form of the ‘if … else’ block, when you only need to choose a value.

Example

At start, the board scrolls ‘Hot’ if the temperature is above 25 °C, ‘Cool’ otherwise.
