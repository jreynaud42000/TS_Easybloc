Block: math_arithmetic

What is it for?

Returns the result of a calculation between two numbers: addition (+), subtraction (−), multiplication (×), division (÷) or power (^).

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Attach a number on each side, then choose the operation in the block's list.

For a longer calculation, put a calculation block inside another one.

Good to know

  • Division gives a decimal number: 7 ÷ 2 = 3.5.
  • A division by 0 stops the program with an error.
  • ‘^’ is the power: 2 ^ 3 = 2 × 2 × 2 = 8.

Example

At start, the result of 3 + 4 (that is 7) scrolls.
