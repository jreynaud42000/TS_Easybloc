LiDAR: set the avoidance distance to … (mm)

Block: lidar_distance_evitement

What is it for?

Sets the distance, in millimetres, from which the LiDAR considers an object as an obstacle to avoid.

How to use it?

Put this block in the ‘on start’ block, after the ‘LiDAR …: set the size 4x4 avoidance’ block.

Good to know

  • On a Maqueen robot, do not go above 200 mm: beyond that, the beam can hit the floor and distort the detection (manufacturer's warning).

Example

The LiDAR is prepared in avoidance mode with a distance of 200 mm, then the advised direction shows every second.
