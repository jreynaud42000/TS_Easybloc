random integer from … to …

Block: math_random_int

What is it for?

Returns a random whole number between the two chosen limits.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Type the smallest and the biggest possible values.

Good to know

  • Both limits can come out: from 1 to 6, the result can be 1, 2, 3, 4, 5 or 6, like a die.
  • A new number is drawn each time the program reaches this block.

Example

A random number from 1 to 6 shows, then another one 2 seconds later, forever.
