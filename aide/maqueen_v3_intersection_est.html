Maqueen Plus v3 : intersection détectée est … ?

Bloc : maqueen_v3_intersection_est

À quoi ça sert ?

Renvoie vrai quand la dernière intersection détectée par le robot V3 est du type choisi (tout droit, à gauche, à droite, stop), faux sinon.

Ce bloc renvoie une réponse vrai/faux (à brancher directement dans un bloc « si », ou dans un bloc de la catégorie Logique).

Comment l'utiliser ?

Choisissez le type d'intersection, puis mettez ce bloc dans un bloc « si ».

À savoir

  • Ce bloc demande un châssis Maqueen Plus V3 : les châssis V1 et V2 n'ont pas ce suiveur de ligne intégré.

Exemple

Un visage heureux s'affiche quand l'intersection détectée est « à gauche ».
