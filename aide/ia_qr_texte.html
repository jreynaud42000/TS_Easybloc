texte du dernier code QR lu

Bloc : ia_qr_texte

À quoi ça sert ?

Renvoie le texte contenu dans le dernier QR code (ou code-barres) lu, ou un texte vide si aucun code n'a été lu.

Ce bloc renvoie un texte (à afficher, ou à comparer à un autre texte avec le bloc « = » de la catégorie Logique).

Comment l'utiliser ?

Placez ce bloc dans le bloc « lorsqu'un code QR est lu » pour réagir à chaque code.

À savoir

  • Le texte arrive sans accents (« Élève » devient « Eleve ») et coupé à 60 caractères.
  • Il reste disponible après la disparition du code, jusqu'au code suivant.
  • La lecture se fait sur l'ordinateur : dans la fenêtre IA, onglet « QR code », cliquez sur « ▶ Lire les codes ». La carte reçoit le texte par le câble USB.

Exemple

Chaque nouveau code lu fait défiler son texte sur la matrice de LED.
